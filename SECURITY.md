# Security Policy

## Authorized use only

socks5scan is a network scanner. **Only scan networks and systems you own or are
explicitly authorized to test.** Unauthorized scanning may be illegal in your
jurisdiction. The maintainers accept no liability for misuse.

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest release (`main`) | ✅ |
| older releases | ❌ (please upgrade and re-test) |

## Reporting a vulnerability

- **Do not** open a public GitHub issue for security vulnerabilities.
- Email the maintainer privately (see the profile email on
  [GitHub](https://github.com/pan8664716)) with:
  - a description of the issue and its impact,
  - reproduction steps or proof of concept,
  - the affected version/commit.

We will acknowledge receipt, investigate, and coordinate a fix and disclosure
timeline with you. Please allow reasonable time for a fix before any public
disclosure.
